## 📖 專案介紹

> *每位玩家的人生，都是一場獨一無二的 RPG。*

**GAMER｜遊戲玩家解鎖成就清單**，是一款專為遊戲愛好者量身打造的互動式成就追蹤平台。  
靈感源自遊戲中令人熱血沸騰的「成就系統」——只是這次，解鎖的不是虛擬世界的勳章，而是你在真實生活中走過的每一段玩家旅程。

從第一次通關 RPG 到在電競賽場拿下冠軍，從午夜鏖戰的主機對決到同好社群的聚會回憶——這份清單，紀錄的是**屬於你的遊戲傳說**。

無論你是剛拿起手把的新手玩家，還是縱橫各大遊戲生涯的老鳥，這裡都有你的舞台。打開清單，開始解鎖你的人生成就吧！

## ✨ 功能特色

### 🏆 成就清單（Achievements Tab）
- **135 項精心設計的成就**，橫跨 5 大遊戲人生分類
- 依難度以 ⭐ 標示，從入門到硬核全覆蓋
- 三種狀態標記：
  - ✅ **已解鎖**：這項成就我拿到了！
  - 🎯 **想挑戰**：列入下一個目標清單
  - ⬜ **未解鎖**：還在等待時機
- 即時顯示解鎖進度與玩家稱號晉升

### 📋 攻略目標（Wishlist Tab）
- 自動彙整所有標記為「想挑戰」的成就
- 一覽所有心願成就，方便規劃未來挑戰路線
- 成為你的個人遊戲攻略本

### 🎴 命運抽卡（Card Draw Tab）
- 隨機從成就庫中抽出一張成就卡牌
- 讓「命運」來決定你的下一個挑戰！
- 抽到不喜歡的？再抽一次！
- 適合選擇困難症玩家的終極解方

### 💬 真心話問答（Q&A Tab）
- **25 題靈魂問答**，深入挖掘你的玩家性格
- 從遊戲習慣到人生哲學，全面剖析你的玩家靈魂
- 分享你的答案，找到同頻的玩家夥伴

### ⚙️ 設定（Settings Tab）
- 設定**玩家暱稱**與**頭像**，打造個人檔案
- 進度**備份與還原**功能，跨裝置不怕資料遺失
- 匯出 JSON 格式，完全掌控你的成就資料

### 🖼️ 個人分享卡
- 一鍵生成**專屬玩家分享卡 PNG 圖片**
- 內含 QR Code，讓朋友直接掃描查看你的成就
- 曬成就、秀紀錄，社群分享超方便！

### 👑 玩家稱號系統
根據解鎖成就數量，依序晉升以下稱號：

| 稱號 | 解鎖門檻 | 說明 |
|------|---------|------|
| 🌱 遊戲初心者 | 0 項 | 旅程的起點，每位傳奇都從這裡開始 |
| 🎮 遊戲愛好者 | 達成一定數量 | 已踏入玩家的世界，感受到遊戲的魅力 |
| 🕹️ 遊戲達人 | 進階解鎖 | 豐富的遊戲歷練，令人刮目相看 |
| 🏆 遊戲大師 | 高階解鎖 | 縱橫各大遊戲，堪稱玩家中的玩家 |
| 👑 傳奇玩家 | 近滿解鎖 | 站在玩家金字塔頂端，傳說級的存在 |

## 🚀 快速開始

### 方法一：直接線上使用 🌐

直接點擊前往 **[線上 Demo](https://ivanusto.github.io/gamer-achievement-list/)**，不需安裝任何東西，打開即用！

### 方法二：本地端執行 💻

只需以下幾個步驟，即可在本機執行：

```bash
# 1. Clone 這個 Repo
git clone https://github.com/ivanusto/gamer-achievement-list.git

# 2. 進入專案資料夾
cd gamer-achievement-list

# 3. 直接用瀏覽器打開 index.html
# Windows：
start index.html

# macOS：
open index.html

# Linux：
xdg-open index.html
```

> ✅ **就這樣！** 純靜態頁面，不需要 Node.js、不需要安裝套件、不需要伺服器。
> 雙擊 `index.html` 就能開始你的成就之旅！

## 🔒 隱私說明

**你的資料，100% 只屬於你自己。**

本專案採用**完全本地儲存**的設計：

- ✅ **零後端**：沒有伺服器、沒有資料庫、沒有雲端
- ✅ **零追蹤**：不收集任何個人資訊，沒有 GA 分析追蹤
- ✅ **localStorage 本地存放**：所有成就進度、暱稱、頭像，全部儲存在你自己的瀏覽器中
- ✅ **隨時匯出**：可透過設定頁面將資料匯出為 JSON 備份，完全掌控
- ✅ **隨時清除**：清除瀏覽器資料即可完整刪除所有紀錄

> 🛡️ 我們相信玩家的回憶應該由玩家自己保管。
